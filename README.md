# Netflix Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a Netflix Movies and TV Shows dataset. The objective is to analyze Netflix content and discover trends, patterns, and insights using Python and data visualization techniques.

## Dataset
The dataset contains information about Netflix movies and TV shows, including:
- Title
- Genre
- Release Year
- Rating
- Duration
- Country
- Vote Average
- Popularity

## Objectives
- Understand the structure of the dataset.
- Clean and preprocess the data.
- Analyze trends in Netflix content.
- Visualize important patterns and insights.
- Draw meaningful conclusions from the data.

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Steps Performed
1. Data Collection
2. Data Cleaning
3. Handling Missing Values
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Insight Generation
7. Conclusion

## Visualizations Created
- Distribution of Movie Ratings
- Top Genres
- Content Released by Year
- Most Popular Movies
- Country-wise Content Distribution
- Correlation Heatmap

## Key Insights
- Movies constitute a major portion of Netflix content.
- Drama and Comedy are among the most common genres.
- Netflix content has grown significantly over the years.
- The United States contributes the largest amount of content.
- Most content is targeted toward mature audiences.

## Conclusion
The Netflix EDA project helped analyze trends, genres, countries, and content types available on Netflix. The analysis showed that Movies are more common than TV Shows, and Netflix has expanded its content library significantly over the years. Through data visualization and exploration, meaningful insights were obtained about Netflix's content distribution and growth.
